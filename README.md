### Halo, gw Radeka 👋

Siswa SMK jurusan Rekayasa Perangkat Lunak (RPL) dari Kepulauan Riau yang suka ngulik dan bikin website. Sehari-hari lagi fokus belajar dan bangun aplikasi web yang simpel, fungsional, dan gampang dipakai.

**Tentang Gw**
* 💻 Lagi sering ngoding pakai PHP, MySQL, dan JavaScript
* 🎨 Suka tampilan UI yang rapi, simpel, dan bertema *dark mode*
* 🛵 Di luar kodingan, suka ngoprek motor dan main game bareng temen

**Bahasa & Tools yang Dipakai**
* **Web:** HTML, CSS, JavaScript, PHP, MySQL
* **Framework CSS:** Bootstrap, Tailwind CSS
* **Tools:** VS Code, Laragon, XAMPP, Git

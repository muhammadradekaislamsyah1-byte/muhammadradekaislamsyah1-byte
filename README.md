### 👨‍💻 Tentang Gw

Gw **Radeka**, *Full-Stack Web Developer* & siswa jurusan *Rekayasa Perangkat Lunak (RPL)*. Di dunia ngoding, gw lebih nyaman dan terbiasa pakai **native stack** (PHP Native, MySQL PDO, Vanilla JS) karena alurnya jelas, ringan, cepat dieksekusi, dan gampang dikontrol dari nol sampai *deployment*.

Pengalaman magang industri selama **6 bulan di departemen HR PT Pepperl+Fuchs Bintan** ngebawa gw langsung terjun bikin aplikasi yang beneran dipakai operasional pabrik sehari-hari—mulai dari ngolah data absensi karyawan, monitoring kontrak, sampai sistem rekrutmen.

- 💻 **Fokus Utama:** *Web Application Development*, *Database Design*, *REST API*, & *System Automation*.
- 🎨 **UI Preference:** *Dark Slate* / *Dark Mode* yang bersih dan fungsional pakai Tailwind CSS & Bootstrap.
- ⚙️ **Eksplorasi Lain:** *Self-hosted Linux server* (Armbian) & integrasi IoT dasar pakai ESP32.

### 📈 Pengalaman & Jam Terbang Coding

- **🏢 Industrial HR System Development (PT Pepperl+Fuchs Bintan)**  
  Merancang dan membangun sistem internal dari nol untuk mempermudah kerja tim HR. Terbiasa menangani logika bisnis yang kompleks, kalkulasi data berskala besar, validasi regulasi kontrak, hingga fitur *export/import* laporan.
- **🎯 End-to-End Web Architecture**  
  Terbiasa ngerjain siklus penuh pembuatan aplikasi: mulai dari perancangan skema database relasional (MySQL), keamanan query dengan **PDO**, logika *backend* dengan **PHP Native**, interaksi *frontend* dinamis pakai **Vanilla JS**, sampai *deploy* ke server.
- **🗺️ Geolocation & Real-Time Logic**  
  Berpengalaman mengintegrasikan API eksternal seperti *Geolocation*, *Leaflet*, dan *OSRM* untuk kebutuhan *GPS tracking* serta sistem presensi berbasis *geofencing* & *QR Code*.
